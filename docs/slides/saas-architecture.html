SLIDE 06

Modelo Multi-tenant

A clínica é o tenant principal. O CNPJ identifica o tenant no cadastro, mas não é a chave de relacionamento.

organizations
├── id
├── legal_name
├── trade_name
├── cnpj_hash
├── cnpj_last_four
├── status
├── plan
├── created_at
└── updated_at
  • CNPJ normalizado (sem pontuação), validado pelo algoritmo oficial, com busca restrita e hash.
  • Tabela organizations com organization_id em todas as tabelas de negócio.
  • Regra fundamental: nenhuma consulta de negócio sem filtro por organization_id.

SLIDE 08

Segurança no Banco

create policy "tenant_isolation"
on public.appointments
for all
using (
  organization_id = public.current_ollclin_organization_id()
)
with check (
  organization_id = public.current_ollclin_organization_id()
);
  • Guard: assertTenantAccess(sessionOrganizationId, requestedOrganizationId) → FORBIDDEN.
  • Três camadas: rota/procedure → serviço de domínio → banco/RLS.
  • A função obtém o tenant da sessão autenticada, nunca de valor livre do navegador.
